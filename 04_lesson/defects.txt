Дефект:Некорректная обработка значения None в функции contains
и в функции delete_symbol
Шаги для воспроизведения:
 1. Вызвать функцию contains с параметрами [None, "a"]
 2. Вызвать функцию contains с параметрами ["Hello", None]
 3. Вызвать функцию delete_symbol с параметрами ["Hello", None]
Ожидаемый результат:
   Функция возвращает корректные результаты
Фактический результат:
   Функция возвращает не корректные результаты, тесты
    завершаются с ошибкой.
Окружение:
OS Windows 10
Python 3.14.7
Pytest 9.1.1
